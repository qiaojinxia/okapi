# 倍率基准价

系统设置 → 高级设置 → 支付与返利分类中的「倍率基准价」以 USD / 百万输入 Token 编辑，最多六位小数。默认 $2，允许 $0.000001–$1,000,000；API 使用整数 micro-USD，不接受零、负数、小数 micro、字符串或 null。

保存仅修改草稿，模型定价显示草稿对应的单价预览。发布时会确认基准变化，也会发布其他定价草稿。前端提交 `expected_base_per_1m_micro` 查询参数，防止另一个管理员修改基准后把未确认的价格发布出去。仍兼容不带该可选参数的既有发布客户端。

发布快照保存基准值；gateway 通过 NATS 或最长约 30 秒的 epoch 轮询更新，重启从已发布 epoch 恢复，不读取未发布的设置草稿。模型广场显示已发布基准。旧 epoch 没有该字段时保持 $2，字段损坏时拒绝加载，不悄悄回退。

影响倍率计费及相对标价的上游成本估算。模型倍率、补全、缓存、模态、分组、个人和规则倍率继续参与原来的乘链。按次价格、阶梯表中的绝对 USD 单价、用户专属绝对价不受影响；修改的是全局价格基准，不是余额单位、USD/quota 汇率或所有价格通用的加价系数。

新账单快照保存本次实际归一化基准 `base_price_per_1m_usd`。绝对单价在内部仍以 $2 归一化；历史账单沿用原金额和原快照，缺基准字段显示旧版 $2，不按当前设置重算。

从 New API 导入的是倍率，不是绝对报价；选择非 $2 基准后，同样倍率不再对应 New API 的相同美元单价。现有导入行为保留，管理员应检查本站单价预览后发布。

此功能不新增数据库迁移，也不默认修改现有设置或发布定价。

## 管理员模型表单与官方预设（2026-09-30）

新建模型支持在模型名称框搜索并选择 25 个已核对的主流预设，或手输自定义 ID。内置预设覆盖 OpenAI、Anthropic、Google、DeepSeek、Alibaba 和 Moonshot；逐项来源和核对日期位于 `frontend/src/features/models/model-presets.ts`，抽屉也提供官方文档链接。它是离线预设，不是运行时抓取或实时更新任务，不按模型名前缀猜测规格。

明确选择候选才带入厂商、类型、输入/输出模态、已声明的能力和上下文/输出限制，以及已核实的缓存倍率。未知能力不填 false；未核实的缓存价格不套用其他厂商折扣。通义千问滚动版本与指定快照的缓存支持分别声明；DeepSeek Flash/Pro 的视觉支持分别声明；Claude 新型号的缓存读取折扣不统一套 0.1。切换预设移除上一个预设的 5m/1h 缓存倍率，不改变输入输出价格、模态倍率、服务档位或降级链；离开预设改成自定义名称会清除其规格与缓存倍率，防止错误继承。

默认编辑 USD/1M 输入、输出单价，精确换算到原有六位倍率，不引入新的固定价格模式。倍率无法精确表示时提示有效单价；非零价格不能舍入成免费。按次价格通过整数 micro-USD 展示和回传。模板、能力、缓存、多模态、服务档位和路由设置折叠展示，折叠不清空配置。

“填入参考价”仅在管理员点击时修改当前表单的输入输出价，并展开适用条件；不会自动保存、发布或改变缓存倍率。参考价采用核对日期的标准文本价格，不代表完整上游账单：GPT-6 长上下文加价、Gemini 长上下文与缓存存储费、DeepSeek 峰谷价、区域差异、图像/音频计价及工具费须另行核对。Gemini 3.8 促销参考价标有截止日期，到期后禁止直接填入。未取得确定参考价的模型仍由管理员设置价格。

编辑已存在模型只显示官方参考，不按预设自动覆盖保存的规格或价格。“用预设替换规格”是显式操作，保留展示名称、说明和全部计费/路由配置。模型能力声明不启用渠道；配置发布与实际接口可用性仍遵守原流程。浏览器回归使用隔离接口桩，不修改真实模型数据。
