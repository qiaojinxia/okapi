# 倍率基准价

系统设置 → 高级设置 → 支付与返利分类中的「倍率基准价」以 USD / 百万输入 Token 编辑，最多六位小数。默认 $2，允许 $0.000001–$1,000,000；API 使用整数 micro-USD，不接受零、负数、小数 micro、字符串或 null。

保存仅修改草稿，模型定价显示草稿对应的单价预览。发布时会确认基准变化，也会发布其他定价草稿。前端提交 `expected_base_per_1m_micro` 查询参数，防止另一个管理员修改基准后把未确认的价格发布出去。仍兼容不带该可选参数的既有发布客户端。

发布快照保存基准值；gateway 通过 NATS 或最长约 30 秒的 epoch 轮询更新，重启从已发布 epoch 恢复，不读取未发布的设置草稿。模型广场显示已发布基准。旧 epoch 没有该字段时保持 $2，字段损坏时拒绝加载，不悄悄回退。

影响倍率计费及相对标价的上游成本估算。模型倍率、补全、缓存、模态、分组、个人和规则倍率继续参与原来的乘链。按次价格、阶梯表中的绝对 USD 单价、用户专属绝对价不受影响；修改的是全局价格基准，不是余额单位、USD/quota 汇率或所有价格通用的加价系数。

新账单快照保存本次实际归一化基准 `base_price_per_1m_usd`。绝对单价在内部仍以 $2 归一化；历史账单沿用原金额和原快照，缺基准字段显示旧版 $2，不按当前设置重算。

从 New API 导入的是倍率，不是绝对报价；选择非 $2 基准后，同样倍率不再对应 New API 的相同美元单价。现有导入行为保留，管理员应检查本站单价预览后发布。

此功能不新增数据库迁移，也不默认修改现有设置或发布定价。
